# 考研英语看板

个人使用的英语二 lite 阅读看板：[手机页面](https://kada666.github.io/kaoyan-english/)。这是静态页；错词和作答记录保存在当前浏览器的 localStorage，可从错题本导出和导入 JSON。跨设备自动同步留到以后。

## 每日内容

- `data/packs.json` 是每日文章的唯一来源。按日期追加 1–2 篇，每天合计 7–10 分钟，每篇 1–2 题。已有日期的题目不改，以免影响作答记录。
- 文章自己写，参照英语二的题材、转折与同义改写，不复制真题段落。目标词来自重点词和阅读词，优先写自然的语境，不为塞词牺牲文章质量。
- 每道题需要四个选项、一个明确答案，以及交卷后显示的一句依据。检查干扰项是否能被文章排除。
- 把新目标词的常见义加入 `data/senses.json`；只有很难从常见义推出来的用法才写 `extended`。词库外的词可在标记后按需补充。
- `data/freq.json` 只记录 2010–2024 年 15 套英语二全文的出现套数。词表未变时不更新它；旧题不进分母。

编辑后运行 `node scripts/check-content.mjs` 检查结构、日期、答案和时长，再在手机尺寸下检查阅读、交卷、错题本、日历和主题。这个脚本不能判断文章原创性或题目质量，仍需人工审读。
